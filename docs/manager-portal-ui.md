# Портал Менеджера (Manager Portal)

Официальная документация по архитектуре, логике и UI/UX решениям портала на Next.js (`apps/web`).

## 1. Динамическая загрузка менеджеров

При загрузке страницы портала (`/manager`) список доступных менеджеров подгружается в реальном времени (динамически). 
Это означает, что больше нет захардкоженных имен (например, "Галина Зиневич").

* **Эндпоинт:** `GET /api/employees/available`
* **Событие загрузки:** Данные запрашиваются при монтировании компонента (`useEffect`), поэтому менеджеры всегда актуальны на момент открытия страницы.
* Менеджеры фильтруются по наличию доступности (флаг `isAvailable` или аналогичный) внутри бэкенда.

## 2. Работа с трекингами заказа (Inline Editing)

* **Просмотр:** Менеджер видит весь трекинг-план заказа. 
* **Редактирование:** Благодаря функции Inline Editing ("Редактировать"), у менеджера есть возможность на лету (и без перезагрузки) изменить любую фазу, сроки или назначенного сотрудника.
* **Сохранение:** При сохранении отправляется вызов на бэкенд `POST /api/tracking/:id/update`, который надежно обновляет запись в базе (Prisma) и меняет состояние UI.

## 3. Синхронизация с Bitrix24 (CRM Sync)

Для того чтобы ручные изменения или новые лиды из Bitrix24 сразу попали в выдачу, на портале реализована кнопка ручной синхронизации.

* **Кнопка "Обновить клиентов"**
* **Эндпоинт:** `POST /api/sync/leads`
* При успешной синхронизации (и получении `200 OK`) интерфейс уведомляет пользователя и перерисовывает данные.

## 4. UI/UX Концепции (SKILL.md)

Интерфейс портала построен строго в соответствии с корпоративными гайдлайнами (`ui-ux-concept`), обеспечивающими премиальный опыт:

* **Интерактивный Custom Dropdown:** Нативный HTML `<select>` заменен на собственную абсолютную компоненту (React overlay), которая поддерживает анимации, Z-index (z-50) и стилистику Tailwind.
* **Micro-interactions:** Все кнопки имеют тактильный отклик (`active:scale-[0.98]`).
* **Shadow Physics:** Глубина объектов выражается через слоистые тени (`shadow-[0_20px_25px_-5px...]`).
* **Typography & Grid:** Оступы выровнены по 4-пиксельной сетке (`py-2.5`, `px-4`), а шрифты используют `tracking-tight`.
* **Focus States:** Добавлены мягкие обводочные кольца (`focus:ring-4`) для доступности и премиального внешнего вида.
